# SijmenR.github.io

Personal academic website, published via GitHub Pages at [www.sijmenrijks.nl](https://www.sijmenrijks.nl).
Replaces the previous Google Sites page (`sites.google.com/view/sijmenrijks`).

## Structure

- `index.html` — homepage (name, affiliation, contact)
- `cv.html` — CV page, embeds `cv.pdf`
- `paper.html` — paper page, embeds `paper.pdf`, includes a "latest version" link back to this site
- `style.css` — shared styling
- `CNAME` — custom domain configuration for GitHub Pages (`www.sijmenrijks.nl`)

## Updating content

- Replace `cv.pdf` / `paper.pdf` with a new file of the same name to update either document.
- Edit the relevant `.html` file directly for text changes.
- Push to `main` — GitHub Pages redeploys automatically.

## PDFs

`paper.pdf` is the compiled Sticky Deposits paper (`Paper 2/00 main.pdf`). `cv.pdf` has not
been added yet — `cv.html` shows a "coming soon" notice until it is.
